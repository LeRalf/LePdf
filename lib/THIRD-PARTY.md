# Bundled third-party libraries

LePdf ships these libraries in `lib/` so that no Composer is needed on the web server.
`lib/` is generated by `tools/build-lib.php`; do not edit it by hand.

## Layout

Every PHP namespace has a folder of the same name: `Mpdf\` is `lib/Mpdf/`, `setasign\Fpdi\` is `lib/setasign/Fpdi/`, and so on.
`lib/data/` and `lib/ttfonts/` belong to mPDF and must stay next to `lib/Mpdf/`, because mPDF finds them by relative path.
The two small mPDF helper packages live inside `lib/Mpdf/`.
License texts are in `lib/licenses/`.

## Version choices

`psr/log` 1.x, `myclabs/deep-copy` 1.13.x and `mpdf/psr-log-aware-trait` 2.x are older series on purpose:
newer releases require PHP 8.0 or later, while LePdf supports PHP 7.4.

## Trimmed content

- `ttfonts/` contains only the DejaVu fonts (and `DejaVuinfo.txt` with their license).
  The full mPDF package ships about 88 MB of additional fonts. Put extra fonts into
  `site/assets/LePdf/fonts/` instead (see README).
- Tests, documentation and development files of the libraries are not included.

## Updating

    php tools/build-lib.php --check    show newer tags in the allowed series
    php tools/build-lib.php            rebuild lib/ from the pinned tags
    php tests/run.php                  run the tests

To update a package, change its `tag` in `tools/build-lib.php` first and check that its PHP requirement still fits.
